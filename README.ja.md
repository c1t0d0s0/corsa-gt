# Corsa GT

[English](README.md) | 日本語

ブラウザで動く 3D の GT レーシング/ドライビングゲームです。[Three.js](https://threejs.org/) と [Vite](https://vite.dev/) で作られており、モデル・テクスチャ・サウンドはすべてコードで生成しているため、ダウンロードが必要なアセットファイルはありません。

## 特徴

- **3 つのコース** — 1km 超のストレートが 2 本ある緑の中の高速サーキット (Apex Circuit)、ネオンが光る夜の市街地 (Neo City Highway)、起伏のある峡谷の道 (Desert Canyon)。
- **時間帯と天候** — 昼・夕方・深夜、晴れ・雨を選べます。雨では路面が濡れて反射し、グリップが下がります。
- **走行モデル** — タイヤが実際に滑る挙動、6 速ギアボックス (AT / MT)、路面ごとに異なるグリップ、すり抜けないバリア。
- **2 段階のアシスト** — 「かんたん」はコーナー手前で自動的に減速し、ハンドルを離すとコースに沿って走ります。「ノーマル」は ABS と弱いトラクションコントロールのみです。
- **4 種類のカメラ** — 追従、ボンネット、コクピット、自由に回せるオービット。
- **ガレージ** — ボディカラー、塗装の仕上げ、ホイールカラー、リアウイング、エンジンチューン。
- **スマートフォン対応** — 横向きで、画面上の操作ボタンとコンパクトな HUD でプレイできます。
- **日本語/英語表示** — ブラウザの言語に合わせて切り替わります。
- **キーボード、ゲームパッド、タッチ**で操作できます。

## はじめかた

[Node.js](https://nodejs.org/) 18 以降が必要です。

```bash
npm install
npm run dev
```

<http://localhost:3000/> を開いてください。開発サーバーはすべてのネットワークインターフェースで待ち受けるので、同じネットワーク上のスマートフォンから PC の IP アドレスを指定して接続できます。

本番用ビルド:

```bash
npm run build     # dist/ に出力
npm run preview   # ビルド結果をローカルで確認
```

相対パスでビルドされるため、`dist/` は任意の静的 Web サーバーやサブディレクトリに置けます。

## 操作方法

### キーボード

| キー | 操作 |
| --- | --- |
| `W` / `↑` | アクセル |
| `S` / `↓` | ブレーキ(停止中に押し続けるとバック) |
| `A` `D` / `←` `→` | ステアリング |
| `Space` | ハンドブレーキ |
| `M` | AT / MT の切り替え |
| `E` / `Q` | シフトアップ / ダウン(MT のみ) |
| `C` | カメラ切り替え |
| `R` | その場でコース中央に復帰 |
| `P` / `Esc` | ポーズ |
| `G` | ガレージ |
| `T` | テレメトリ |

上部バーの **リスタート** ボタンを押すと、スタート地点からやり直します。

### ゲームパッド

標準レイアウト(Xbox のボタン名):

| 入力 | 操作 |
| --- | --- |
| 左スティック | ステアリング |
| RT / LT | アクセル / ブレーキ |
| A | ハンドブレーキ |
| B / X | シフトアップ / ダウン |
| Y | カメラ切り替え |
| Back | コース復帰 |
| Start | ポーズ |

### タッチ

端末を横向きにして持ちます。縦向きにするとゲームが一時停止し、回転を促す表示が出ます。

- **左親指** — ステアリングパッド。パッドのどこかに触れて左右にスライドします。触れた位置が中心になります。
- **右親指** — `GAS` と `BRAKE`。停止中に `BRAKE` を押し続けるとバックします。
- **`HB`** — ハンドブレーキ。**`↺`** — コース復帰。

タッチ操作では AT のみです。スマートフォンサイズの画面では、車が隠れてしまうためテレメトリは表示できません。

## 表示言語

ブラウザの優先言語が日本語なら日本語、それ以外は英語で表示します。URL に `?lang=ja` または `?lang=en` を付けると切り替えられます。

## URL パラメータ

デモやスクリーンショット、テストに使えます。`/?track=city&tod=midnight&weather=rainy` のように組み合わせられます。

| パラメータ | 値 | 効果 |
| --- | --- | --- |
| `track` | `apex`, `city`, `desert` | 最初のコース |
| `tod` | `noon`, `sunset`, `midnight` | 時間帯 |
| `weather` | `rainy` | 雨で開始 |
| `cam` | `chase`, `hood`, `cockpit`, `orbit` | 最初のカメラ |
| `lang` | `en`, `ja` | 表示言語を固定 |
| `touch` | `1` | PC でもタッチ操作 UI を表示 |
| `autostart` | `1` | スタート画面を省略(サウンドなし) |
| `autopilot` | `1` | 自動運転 |
| `t` | 秒数 | 最初のフレームの前にシミュレーションを早送り |

## チェック

```bash
npm run check           # 物理とコースレイアウト。Node 上でヘッドレス実行
```

以下はヘッドレス Chromium で実際のアプリを操作します。先に `npm run dev` を起動してください。`PATH` 上の `chromium` を使います(別のバイナリを使う場合は環境変数 `CHROME` で指定)。

```bash
npm run check:browser   # メニュー、カメラ、キーボード走行、コース切り替え
npm run check:mobile    # スマートフォンのレイアウトとマルチタッチ操作
npm run check:i18n      # 表示言語の切り替え
npm run check:audio     # エンジン音(音程、音量、音割れなし)
```

いずれも、URL とスクリーンショットの出力先ディレクトリを引数で指定できます。

```bash
node scripts/mobile-check.mjs http://localhost:3000/ ./shots
```

ヘッドレス Chromium はソフトウェア描画になるため、完了まで数分かかります。

## ディレクトリ構成

```
index.html              ページのマークアップ(HUD、メニュー、タッチ操作)
src/
  main.js               エントリーポイントとゲームループ
  i18n.js               日本語/英語の文言
  style.css
  engine/
    Physics.js          車両挙動、運転アシスト、ラップ計測
    Renderer.js         WebGL レンダラー、ポストプロセス、画質の自動調整
    Environment.js      空、ライティング、フォグ、映り込み
    CameraRig.js        カメラモード
    CarModel.js         プロシージャル生成の車
    TrackBuilder.js     路面、縁石、バリア、スタートライン
    Scenery.js          地形、樹木、市街地、峡谷
    Effects.js          タイヤスモーク、スキッドマーク、雨
    ProceduralTextures.js
    AudioEngine.js      エンジン・排気・ターボ・風・タイヤ音の合成
    track/              コース定義とセンターラインの検索
  ui/                   HUD、テレメトリ、ガレージ、コース選択、タッチ操作
  utils/                入力処理、数学ユーティリティ
scripts/                チェック用スクリプト
docs/screenshots/       README 用の画像
```
